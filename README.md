# 课程表

ClassSchedule，使用Bee图标的Windows WPF桌面程序：每名学生独立学期配置与课程，支持每日8/10节、统一单/双节、多周次多地点安排。

- 直接运行发布后的 `dist/ClassSchedule.exe`，Windows x64依赖框架单文件，不捆绑.NET；需要.NET 10 Windows Desktop Runtime（x64）。缺少运行时时，原生.NET启动宿主提示安装并提供下载入口。
- 从设置齿轮菜单打开独立“学生管理”窗口，可新增、更新姓名及删除学生；打开时不选中学生、姓名为空；姓名框宽为列表一半，靠右且文字居中；默认单节。学期和课时通过“总体设置”调整。课程数为0时可改模式，有课程时锁定；删除全部课程并保存后可再改。
- 学生管理窗口320×340 DIP，姓名列表采用课程管理相同的36 DIP行高、14 DIP字体、交替底色和柔光选中。
- 重复启动会恢复并激活已有窗口；若已有弹窗则激活该弹窗，不创建第二个程序窗口，也不永久置顶。
- 删除学生在管理窗口底部确认“是否删除‘某某’的全部课程信息？”，选择是才删除JSON及.bak；否或Esc取消，默认焦点在否。更新姓名保留全部课程与设置。
- 双击空白格新建课程，双击课程块编辑整门课程；“管理课程”可找到其他周的课程。
- 课表滚轮切周，主窗口不显示左右切周按钮。所有错误/警告在当前窗口底部依次显示约5秒。
- Enter保存/确定，Esc取消确认或请求关闭。离开未保存页面时提供保存、放弃修改、继续编辑；设置保存成功或取消修改后关闭，课程保存返回列表。课时表编辑中的Enter优先提交单元格。
- 主窗口与总体设置默认600×600 DIP，课程管理520×540 DIP；主界面仅88 DIP学生选择框、周次、本周和设置齿轮。菜单依次为开机启动、总体设置、课程管理、学生管理、更新学生信息；最后一项重新扫描并加载学生文件。总体设置独立开窗，课程列表与编辑在课程管理窗口内切页，子窗口相对父窗口居中。课时预览只在总体设置显示，刷新直接执行，无确认或成功提示；错误仍在底部显示。
- 总体设置的基本信息和课时参数默认并排，窄窗口自动上下排列；单选项列对齐，时长/课间单位位于数字框后，时间选择框宽43 DIP。
- 设置页滚轮统一滚动整页，日历浮层内则每次切一个整月，仍只可选周一。时间下拉无箭头、最多4项、细滚动条；浮层内滚轮只滚动选项，保持展开且不改选值；浮层外滚轮先收起列表，再滚动页面。
- 管理课程为“课程名/周次/时间/地点”四列，同课时段聚拢、名称纵向合并，按周次与时间排序。双击空白新建，双击课程组编辑，下方新建/删除/确定，确定关闭。
- 周次输入如1-5, 7, 8；时间使用401（周四第1节）或30102（周三第1/2节），星期仅一位、周日7。课程编辑使用承载窗口剩余空间，时段窗口320×390 DIP；标题右侧＋新增，双击时段表空白新增、实际行编辑；表格最多显示5行，更多时段内部滚动。
- 全程序滚动条统一11 DIP，下拉文字14 DIP、浅色圆角悬停；参数标签14 DIP、注释12 DIP。时段窗口横排对齐，课程表选中使用半透明浅蓝柔光，管理表按课程组交替底色；名称中心保留原色，仅圆角边缘渐变至白色。管理表前三列宽120/110/70 DIP，地点占剩余空间。
- 课程颜色自动生成，仅在名称后显示只读色块，无备注。课程提醒次数/间隔默认3次/3分钟，时段提前提醒默认30分钟。

**数据已破坏性升级为schemaVersion 2，旧格式及note字段不兼容；原JSON和备份不会自动删除，需要保留原文件后重新创建。**

提醒仅针对当前学生；未来课程的首次提醒若已过点，加载或切换时立即启动完整一轮。每次默认1分钟，时长可设且不能超过间隔，关闭当次仍按间隔继续；程序退出停止提醒。声音和闪烁参考MySchedule。所有窗口不限制最大尺寸，禁用最大化按钮，仍可边缘缩放。

数据位于正在运行的EXE旁 `data/姓名.json`，更新保留上一份 `姓名.bak`。请把程序放到可写目录。文件出错或被外部修改时程序拒绝覆盖；备份恢复须先关闭程序并手动备份原文件。不要同时用外部编辑器写入文件。

## 开发和验证

需要.NET 10 SDK和Windows：

```powershell
dotnet build src/ClassSchedule/ClassSchedule.csproj
dotnet run --project tests/ClassSchedule.Tests
dotnet build tests/ClassSchedule.UiChecks -m:1
dotnet tests/ClassSchedule.UiChecks/bin/Debug/net10.0-windows/ClassSchedule.UiChecks.dll
dotnet run --project src/ClassSchedule/ClassSchedule.csproj
./Publish.ps1
./tests/RuntimeChecks.ps1
```

测试为无第三方测试框架依赖的可执行断言程序，失败时返回非零退出码。RuntimeChecks检查已发布EXE的缺失.NET提示，使用临时副本及子进程环境，不修改本机运行时或真实学生数据。断网且已缓存所需运行时包时可用 `./Publish.ps1 -Offline`；该选项明确跳过在线NuGet漏洞检查。

日常修改按影响范围验证，不默认运行全部检查。底部确认和课程时段操作的针对性检查：`dotnet tests/ClassSchedule.UiChecks/bin/Debug/net10.0-windows/ClassSchedule.UiChecks.dll --confirmations`；需要完整回归时再运行无参数检查。

发布脚本不删除已有data。调试、发布各自使用输出目录旁的数据，不自动复制真实学生文件。

设计、数据契约、验收与验证记录见 [docs](docs/README.md)。

## 托盘与开机启动

主窗口叉号或最小化隐藏到托盘，提醒继续运行；双击bee托盘图标或右键“打开”恢复窗口。右键“退出”才结束程序；如有未保存编辑，按内到外在对应窗口底部询问“是否保存修改？”，是保存、否放弃，未选择或保存失败时不退出。重启不恢复草稿。

设置齿轮顶部“开机启动”首次默认勾选，取消后保留选择。手动启动显示窗口，开机通过 `--startup` 启动只驻留托盘。再次运行仅唤起已有实例，不永久置顶。程序级偏好在EXE旁的 `ClassSchedule.settings.json` 中保存，仅含布尔值 `startWithWindows`，独立于学生JSON。Release注册当前用户的 `ClassSchedule` Run启动项，命令为带引号的EXE路径及 `--startup`；Debug和定向测试不更改真实启动项。设置失败在主窗口底部提示，损坏文件不覆盖；需使用有写入权限且位置稳定的程序目录。

托盘、启动偏好及退出确认的定向检查：界面测试加 `--tray-startup`；加 `--tray-smoke` 可短暂创建真实托盘图标，注册表回调仍隔离。此检查不是系统重启验收。

本轮定向验证：核心测试加`--reminders`，界面测试加`--course-reminders`；可选`--sound-smoke`短暂验证原生声音及编辑模态窗口并存。

提醒时长、空姓名列表和姓名留白的定向检查：界面测试加`--duration-selector`，不执行全面回归。

本轮时段表紧凑布局的定向检查：界面测试加`--compact-slots`。

主界面焦点稳定、圆角裁剪及课程编辑对齐的定向检查：界面测试加`--layout-stability`。

普通按钮按下效果、菜单及弹窗返回状态的定向检查：界面测试加`--button-feedback`。
