# 学生与课程管理修订验证（2026-10-29）

依据：[修订计划](../design/student-management-plan.md)、当前[需求](../requirements/requirements.md)与[数据契约](../requirements/data-model.md)。

## 修改内容

- 新增学生独立姓名小窗，默认蜡笔小新；创建完整单节配置，不显示设置或预览。
- 设置页与保存层都以已保存课程数控制模式更改：0可改，有课程禁止；删除全部并保存后重新允许。
- 刷新提交当前单元格后立即生成，不确认、不提示成功；参数错误仍显示底部消息且不替换原表。
- 设置滚轮统一滚动外层页面；时间下拉无箭头及预留空间，4项视口、9 DIP滚动条，滚轮不改选值。日历滚轮只切整月，不改所选日期；相邻月日期隐藏并禁点。
- 管理课程独立为两列表格，下方仅新建/删除；命中实际行才编辑，空白即使有旧选中项也新建，排除表头与滚动条。
- CourseTimeCode提供Encode、Decode和Format，按个人设置验证；周次展开后按周/星期/开始节数值排序，以英文逗号+空格连接。JSON不加重复编码字段，schemaVersion仍为1。

## 自动检查

最终构建零警告、零错误。26组核心检查及55项STA线程WPF控件检查通过：

```powershell
dotnet build ClassSchedule.sln -m:1 --no-restore --nologo
dotnet tests/ClassSchedule.Tests/bin/Debug/net10.0/ClassSchedule.Tests.dll
dotnet tests/ClassSchedule.UiChecks/bin/Debug/net10.0-windows/ClassSchedule.UiChecks.dll
```

新增覆盖：模式0课程可改/有课程禁改/先删除保存后可改、同次删除改模式拒绝；新建默认姓名/单节/周一锚点；学生切换重新读取各自JSON；编码单/双节往返、周日07、10节、非规范前导零、周次和节次越界、非法配对、ASCII及数值排序；刷新无确认和成功消息；日历翻月不改选日或页面位置；下拉4项与细滚动条、拖动滚动条只滚动选项不改值、滚轮转发页面并收起；管理表空白/行/表头双击及两个底部按钮。

TDD证据：编码类缺失时先编译失败；补齐后零课程模式变更测试在旧锁定规则上失败，再修正规则通过。WPF测试发现原生日历的本地Visibility覆盖模板触发器，改为隐藏日期内容并禁点；还发现下拉浮层已处理的滚轮需要继续关闭列表，改为接收已处理事件但不重复滚动。以上回归均已通过。

## 真实窗口操作

通过computer-use在隔离测试学生目录运行真实WPF窗口，非真实学生文件：

- 日历从2026年10月滚轮切到11月，仅当月日期显示，原选中日期不变，设置页面位置不变。
- 在数字框及下拉列表上滚动，整页移动；下拉收起，分钟仍为00。列表实际显示00/05/10/15四项及细滚动条，无箭头。
- 点击刷新直接更新表格，未出现确认区域、成功提示或底部消息。
- 管理表先选择已有课程，再双击空白，实际打开新建课程；取消后双击课程行，打开编辑课程。表格仅课程名和编码两列，下方仅新建/删除，Esc可关闭。
- 新增学生只有姓名，默认蜡笔小新；创建后单节，零课程时设置中模式可选；改为双节保存后检查隔离JSON，classesUnit为two且courses为空。
- 独立对话框观察为父窗口居中，进程内检查同时测量新增学生和设置中心位置。
