# 紧凑界面验证（2026-10-29）

本文件保留该轮历史验证结果。后续新增学生、模式切换、滚轮和管理表的最新结果见[学生管理验证](2026-10-29-student-management.md)。

需求及范围见[紧凑界面计划](../design/compact-ui-plan.md)。本次不改变JSON字段、单双节固定模式或运行时打包方式，不迁移/凑整用户课时数据。

## 改动

- 主窗口600×600 DIP、屏幕可用区中央启动，最小520×480；工具区两行，时间列78 DIP、11号文字，七列均分剩余宽度。
- 新增学生/设置600×600且相对owner居中，纵向分组和滚动，底部按钮及提示固定；课程600×600、管理600×500、时段480×420。
- 圆角文本框和下拉框；只读日期标签及日历图标，圆角浅色日历仅可选周一。
- 四类数字文本框限制ASCII数字；周数、时长最多3位，奇偶课间最多2位且0–99；保存时拒绝空值和超范围值。IME、拖放禁用，粘贴校验完整替换结果。
- 三段起点的小时和分钟按已确认列表选择；旧小时/分钟不在列表内时明确显示原值，部分选择不改源值，完整选择才更新草稿。
- 课时预览去掉两处说明，右侧刷新图标代替文字按钮；五列等宽，行及表头28 DIP，文字双向居中；4/8/末节课后间隔为—。生成重叠时保留原表格。
