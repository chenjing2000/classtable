# 普通按钮按下与键盘焦点效果（2026-11-02）

## 修改

原普通Button模板用IsKeyboardFocused驱动蓝色粗边框；鼠标点击后WPF会保留键盘焦点，弹窗关闭或菜单返回时也会恢复焦点，导致边框持续显示。

全局普通Button样式现用IsPressed驱动原有叠加描边，按下显示、释放恢复；悬停底色保持。键盘导航提示使用WPF的FocusVisualStyle机制提供独立圆角蓝色描边，保留按钮Focusable、Tab停靠及原有Click处理，不通过禁用焦点或清空全局键盘焦点解决外观问题。两类描边均不改变布局尺寸。

删除学生管理返回后无条件对主窗口齿轮调用Focus的代码。底部确认区默认聚焦否/取消、日历键盘返回按钮及输入框等必要焦点逻辑保留。普通按钮统一继承公共样式；下拉框、单选框、日历日期按钮及表格内部按钮等独立控件模板不作统一改写。
