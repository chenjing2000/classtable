# 主窗口稳定性与课程编辑布局验证（2026-11-02）

## 问题与修改

原按钮模板在获得焦点时将边框从1 DIP改为2 DIP。修改前真实WPF布局测量得到按钮高度36.00 → 37.78 DIP，课程表的位置与高度随之变化。焦点描边现以独立叠加层显示，不参与按钮内容测量；修改后36.00 → 36.00 DIP。

主窗口原来在本周、刷新、管理窗口返回等操作时无条件清空课程表。现保留学生名、文件指纹和周次作为上次绘制状态；未变化时跳过重建，姓名列表内容相同时也不重新赋值。标题与学期状态仍每次更新。存储使用克隆快照，实际数据保存改变指纹；切换周次或学生也会触发重建。

外层Border的圆角不裁剪子元素。内部表格现用随SizeChanged更新的RectangleGeometry裁剪，内圆角11 DIP，对应外圆角12 DIP和1 DIP边框。没有添加覆盖四角的遮挡控件。

课程名称及提醒次数使用同一表单标签列；新增时段按钮由32改为24 DIP，内容居中。原有双击编辑、空白新增及五行视口保持。
