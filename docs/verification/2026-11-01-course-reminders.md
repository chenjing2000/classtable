# 课程提醒、schema2与编辑界面修订

按[确认计划](../design/course-reminders-plan.md)实施。

## 改动

- 全部“学生课程表”文字统一为“课程表”。设置保存成功或取消修改后关闭，失败仍保留输入；日期变更确认仍存在。课程列表初始无选中、确定关闭；学生管理初始无选中/空姓名，姓名框半表宽、靠右、内容居中。
- 课程名称后只读颜色块，无颜色编辑和备注；次数/间隔默认3次/3分钟。时段表最后一列为提前提醒，默认30分钟，无操作按钮。时段窗口320×390，提前分钟数字框，删除靠左、取消/保存靠右；删除与取消直接丢弃输入并关闭，时段改动仅更新课程草稿。新增未保存时段也可删除。
- 所有生产窗口不设置最大宽高，只初次定位适配工作区；保留最小尺寸、边缘缩放，原生最大化样式位禁用。
- schemaVersion=2，Course.Note移除，新增课程reminderCount/reminderIntervalMinutes及schedule.reminderMinutes，字段均必需。旧字段/旧版本拒绝加载，不自动迁移或删除原JSON及备份。
- ReminderSession独立计算当前学生每次具体课程的提醒；加载前已开始的课不补，未来课若首次提醒已过则立即完整开始；每次实际开始计算下次间隔。未改计划在同学生保存后保留轮次，切换清空；开始过的一轮允许在上课后完成剩余次数。
- ReminderService协调秒级检查和最多60秒的可合并提醒窗；手动关闭停止当前声音/闪烁/临时置顶，但不取消后续次数。非模态提醒窗在课程编辑模态窗口打开时仍可关闭，不影响草稿；程序退出停止全部提醒，不增加后台服务。
- 仅借用MySchedule的原生循环播放、双音PCM波形和闪烁机制，无日历程序集或第三方依赖。

## 验证

- 新核心用例先编译失败暴露缺失能力，完成后定向运行`ClassSchedule.Tests --reminders`，15组通过；包含严格格式、默认值、正常/迟加载/零提前、已开始课、未来周次、间隔次数、切换、同学生保存去重、跨午夜/周日归属、字段克隆转换与同刻多条提醒。
- `ClassSchedule.UiChecks --course-reminders --sound-smoke`，35项通过；覆盖上述窗口/字段/按钮布局/草稿边界、设置失败留窗和确认日期保存关闭、未保存时段删除、60秒模拟时钟到期及手动关闭后重复。
- 原生效果烟测：WinMM播放无错误返回，编辑模态仍打开时新提醒窗可操作且启动闪烁/临时置顶；关闭后声音停止调用成功、计时器停止、置顶解除，编辑窗不被关闭。生成PCM长度和RIFF头也验证通过。未以自动调用成功宣称进行了人工听感评估。
- 独立只读复查未发现确定的必修错误；按其建议补了真实音频与模态并存烟测。
- 最终编译0警告、0错误。按用户要求未运行核心或界面全面回归；受影响的旧断言已更新，但不宣称完整旧套件通过。
- 已更新dist/ClassSchedule.exe，依赖框架单文件611977字节，不包含.NET；离线发布未执行在线漏洞审计。发布前后真实学生JSON及备份全部路径与SHA-256一致。v2文档示例、33份Markdown本地链接和git diff --check通过。

## 边界

未穷举所有DPI/显示器/前台策略、人工音色听感、系统时间跳变或实际连续等待一分钟的长时测试；一分钟生命周期通过可控时钟验证。重启不持久化提醒轮次，按已确认规则重新计算；已有v1文件不会在新版本加载，需要保留原文件后重新创建。
