# 托盘、开机启动与退出确认实施方案

已确认：首次默认开机启动；设置齿轮首项为“开机启动”及右侧勾选框，其后有对称分隔条。手动启动显示主界面，`--startup`启动仅驻留托盘。关闭或最小化主窗口隐藏到托盘；双击托盘、打开菜单及第二实例恢复原实例。不永久置顶。

托盘参考MySchedule的NotifyIcon与WPF圆角菜单实现，项目内直接实现具体服务，不引入框架。菜单为“打开”“退出”，在外侧点击可关闭。退出按内到外处理未保存编辑：对应窗口底部“是否保存修改？”及右对齐的是/否；未决定不能退出，保存失败继续留在窗口。跨进程不保存或恢复草稿。

## 实施步骤

- [x] 启动设置：独立JSON及当前用户启动注册，首次默认、关闭保留、失败回滚、损坏文件保护。测试使用注入回调，不写真实启动项；Debug不注册真实启动项。
- [x] 托盘与单实例：隐藏/恢复共享一条路径，恢复嵌套窗口，显式退出，释放图标/事件；自动启动不闪主窗口。
- [x] 退出协调：各编辑窗口提供具体保存操作；底部是/否阻止关闭/Esc绕过，失败可修改后重试；时段先保存父课程草稿，再确认父课程保存。
- [x] 菜单：内容自适应宽度、可勾选模板、两条分隔线左右对称，托盘紧凑样式参考MySchedule。
- [x] 定向WPF/存储/子进程验证、全面代码审查与发布完成，文档和日志已更新；提交推送与远程核对在本批交付时执行。

## 验证重点

启动项与JSON失配/失败不能误显示成功；不覆盖损坏数据；隐藏主窗口时提醒继续且能弹出；嵌套模态窗口隐藏后可恢复；退出确认默认否且按钮右对齐，保存失败不能退出；第二实例不能创建托盘或改启动项；无论人工还是自动启动均只有一个实例；真实学生数据保持，测试注册表项隔离。
