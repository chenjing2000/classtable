# 课程分组表与时段输入（用户已确认）

历史阶段方案；当前样式和时段尺寸以[统一UI修订](unified-ui-plan.md)与当前requirements为准。

- 课程颜色用#RRGGBB文本框+预览；新建时在当前学生已有色相的最大空档中部随机选柔和颜色，编辑不重新选色。
- 周次仅ASCII数字、英文连字符/逗号/空格，解析去重排序、显示压缩连续区间；保留单/双周筛选。
- 时间改为一位星期+两位节次，双节再追加两位结束节，例如401、30102；按学生模式检查配对。
- 课程窗口540×600；时段共用新增/编辑窗口320×420，标签在上输入在下。课程时段表为周次/时间/地点/操作，只读，实际空白双击新增、实际行双击编辑，去掉下方添加按钮。
- 管理课程四列：课程名/周次/时间/地点。按课程ID分组，名称纵向合并居中；每条时段独占一行，组内先最早周次、星期、开始节，再完整周次集合与地点稳定排序。选任意组内行突出整组，删除整门课程并确认；双击任意组内位置编辑整门，真正空白新建。
- 不增加第三方UI库；统一滚动区域内用Grid行跨度合并名称单元格，表头固定。JSON保持结构化时段及schemaVersion=1，不保存重复展示字符串。

实施顺序：规则失败测试与实现→窗口与WPF检查→原生交互、审查和文档→保留data发布。不初始化Git、不推送、不更改发布方式。
