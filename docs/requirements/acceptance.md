# 课程表验收清单

依据[产品需求](requirements.md)和[数据格式](data-model.md)。以下均为待执行的验收项目，勾选前需有实际验证证据；设计草案的待审阅建议不作为已确定验收条件。

第一版已实施的分层验证见[2026-10-29验证记录](../verification/2026-10-29.md)。此清单含尚未完整测试的DPI和键盘矩阵，因此不统一标记全部通过。

- [ ] EXE 同级 `data/` 每位学生一个 JSON，文件名即下拉显示名，设置与课程都在本人文件内。
- [ ] 学生下拉框无三角形，显示框与下拉外框同为88 DIP；设置齿轮圆角菜单依次为总体设置/课程管理/学生管理/更新学生信息，末项重新扫描文件并更新课程。
- [ ] 无右侧课程列表；顶部仅第 N 周，无日期区间；主窗口不显示左右切周按钮，保留回到本周；课表鼠标滚轮可切周。
- [ ] 周一至周日标题均显示准确日期，周日不显示“下一周”字样。
- [ ] 周日归属=上一周时周日在最后；=下一周时周日在最前，周次与实际日期正确。
- [ ] 学期首个周一强制校验星期一；总周数为个人设置，当前周自动计算。
- [ ] 基础设置依次为总周数、第一周周一、周日归属及提示、每日课时、课程模式、今日颜色。
- [ ] 课程设置默认45/10/20；总周数、时长及两类课间为受限ASCII数字文本框，课间最多两位，0–99分钟。
- [ ] 8节=4上午+4下午，10节再增2晚上；逐节起止时间由参数生成，午晚休不被短课间规则覆盖。
- [ ] 课程双击空格新建/有内容编辑；单门课程可以配置多个不同周次、日期、节次、地点。
- [ ] 课程编辑表列顺序：上课周次、时间、上课地点、提前提醒（分钟）；双击已有行编辑，没有额外的全课程上课周次区域。
- [ ] 添加/修改单条时段使用独立弹窗；可选不连续上课周次。
- [ ] 单节模式只选一节；双节模式仅支持1~2、3~4、5~6、7~8、9~10等成对节次（按8/10过滤）。
- [ ] 主表课程块只显示名称与地点，不显示教师；同课同色；双节合并块视觉跨两行。
- [ ] 对同一学生不同课程时间冲突、周次越界、跨学期、空课程名等情况有清楚校验。
- [ ] 学生之间切换设置与课程不串数据；不合法 JSON、空目录、保存失败与文件变更有安全提示。
- [ ] Windows DPI 与窗口缩放正常，弹窗不截断、Tab/Enter/Esc 及键盘焦点行为合理。

## 本次讨论确认的补充项

- [ ] 主窗口600×600 DIP、屏幕居中；总体设置600×600、课程管理520×540；学生管理320×340，空列表默认空姓名；所有独立子窗口相对直接父窗口居中。
- [ ] 日期只读标签与日历图标垂直居中，日历仅可选周一；所有文本框圆角。
- [ ] 上午小时8–11、下午13–16、晚上18/19；分钟00..55步长5，不允许自由输入，不静默更改旧起点。
- [ ] 课时预览仅标题和右侧刷新图标，无格式说明和下方提示；五列等宽、行等高，单元格双向居中，4/8/末节间隔为—。

- [ ] 采用WPF结合简单MVVM，仅支持学生单学期、8/10节和固定单/双节范围。
- [ ] 程序内可新增学生，空目录可进入创建流程，不要求手写JSON。
- [ ] JSON使用classesPerDay、classesUnit（one/two）、classPeriods；姓名取自文件名。
- [ ] 新学生默认单节；课程数0可在设置中改模式，有课程则锁定；删除全部并保存后可再改，保存层同样检查。课程和时段不能选择不匹配的模式。
- [ ] 地点允许留空并保存为""，重新加载后仍正确显示。
- [ ] 设置集中一页，默认值重置颜色和课程参数草稿，保存前重新生成只读预览，失败保留草稿。
- [ ] 独立管理课程入口可找到未出现在当前周的课程；主页仍无右侧课程栏。
- [ ] 管理表为课程名/周次/时间/地点四列，同课按ID聚拢、名称纵向合并，每条时段一行，按周次与时间排序，下方仅新建/删除，Esc关闭；已有选中项时双击空白仍新建，双击实际行编辑，表头双击不建课。
- [ ] 单节401、双节30102编码及解码正确，周日7；周次输入仅ASCII数字、英文连字符/逗号/空格并压缩显示；JSON不重复存编码。
- [ ] 课程颜色为文本框加预览，新课程按已有色相空档生成建议色，编辑保留颜色。
- [ ] 课程编辑页使用520×540课程窗口、时段320×390；双击时段表真实空白新增、实际行编辑；标题右侧＋新增，默认5行可视区，更多时段内部滚动，无额外空白行。
- [ ] 只有总体设置显示课时预览，刷新直接执行，无确认/成功提示，异常仍底部报错并保留表格。
- [ ] 设置所有区域滚轮统一滚动整页；日历内按一个整月切换，仅当月日期可见，仍只可选周一。
- [ ] 时间下拉无箭头或预留空间、最多4项、滚动条统一11 DIP，滚轮不改变选值。
- [ ] 周日归属切换前后，逐门课程实际日期集合相同；周次和学期范围自动调整，不要求用户手动处理越界课程。
- [ ] previous→next末周周日溢出时自动增加总周数；反向首周周日变为第0周时自动前移锚点并重算所有课程周次，所有日期不变。
- [ ] 同一课程内部重复和不同课程冲突均禁止保存，给出具体原因。
- [ ] 错误在对应窗口底部逐条排队，用户关闭或对应操作成功后滑出。
- [ ] 普通提示最新在上，保留三条，停留4秒并用0.6秒向下滑出。
- [ ] 保存失败不关闭编辑窗口、不丢失草稿、不修改已保存数据；取消子窗口或父窗口不泄漏未保存修改。

- [ ] 总体设置与课程管理独立窗口，课程列表/课程编辑在课程管理内切页，单时段为课程子弹窗；不保留跨设置/课程导航。
- [ ] 时间浮层滚轮只滚选项且不收起/不改值/不穿透，表格区域仍滚全页。
- [ ] EXE与窗口使用Bee图标，项目引用/发布标识统一ClassSchedule；课程页和总体设置标题居中，姓名垂直居中。

- [ ] 时段表显示5行（表头另计），多行内部滚动；＋靠右且始终可新增，窗口缩小时按钮可达。

- [ ] 展开时间列表后，鼠标在页面其它位置滚动，同次事件关闭浮层并滚页。

- [ ] 所有窗口禁用最大化而无限制最大尺寸。

## 托盘与退出验收

- [ ] 开机启动默认勾选，取消后重启保持；失败不覆盖损坏设置，界面提示错误。
- [ ] 手动启动显示窗口；自动启动隐藏且不抢焦点；初始化期间手动唤醒不能被再次隐藏。
- [ ] 主窗口叉号/最小化隐藏，托盘双击/打开及第二进程恢复唯一实例；嵌套编辑可恢复。
- [ ] 托盘菜单打开/退出、圆角及宽度与参考一致；主菜单首项可勾选，两条线左右对称。
- [ ] 未保存编辑退出时按内到外询问，底部是/否靠右、默认否；叉号/Esc不绕过，验证或保存失败不退出，否放弃。
- [ ] 隐藏时新提醒可见，过期提醒不被恢复；真正退出释放托盘、提醒声音、计时器及单实例资源。

## 提醒弹窗验收

- [ ] 到期恢复主窗口，提醒窗口以其为所有者居中且置顶；指定字体、颜色、粗细、四行居中、按钮等宽居中及8 DIP间距正确。
- [ ] 空地点连同@省略；再次提醒只追加对应一次课、不影响其他周次/课程、不改JSON，末次也可追加，间隔不从点击时重算。
- [ ] 确定/叉号/超时不追加，声音与闪烁正常停止；多事件独立、学生切换和退出释放全部窗口。

- [ ] 各窗口提示与可用内容等宽，背景透明度25%，可覆盖页脚，长消息可滚动。
