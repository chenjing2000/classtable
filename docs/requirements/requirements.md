## 总体目标

Windows 11 风格，浅色、圆角、清晰留白，适用于学生查看每周课程并通过双击直接编辑。采用 Windows / .NET / WPF，结合简单 MVVM。第一版严格限定学生、单学期、8/10节、每人统一单节或双节，不增加其他通用场景。

## 文件、学生与设置范围

- 已发布 EXE 同级的 `data/` 文件夹保存所有学生数据；文件名为学生姓名，如 `data/张三.json`，一人一个 JSON。单个 JSON **同时包含这名学生的全部课程、个性化总体设置**。不存在统一共享的全局 `settings.json`。
- 提供“新增学生”姓名小窗，默认姓名“蜡笔小新”，不重复显示基本信息、课时参数或课时预览。默认单节、每日8节、20周、第一周周一为当前自然周周一；之后通过总体设置调整。显示姓名取自文件名，JSON不重复保存studentName。
- 增加独立“管理课程”入口，便于查找和编辑未出现在当前周的课程；主页仍不增加右侧课程栏。
- 主页第二行是无下拉三角符号的圆角学生选择框；显示 JSON 文件名去掉 `.json` 的部分。通过点击整个框展开列表，多个学生可切换。
- 学生选择框右侧依次为仅显示加号的“新增学生”（tooltip保留完整名称）、仅图标的「刷新」（循环箭头）和「总体设置」（齿轮）三个按钮，带 tooltip。刷新时重新扫描 `data/*.json`、读取当前学生的设置及课程、重绘当前周；如当前文件被删除，选择首个可用学生并提示。需要处理空目录、非法 JSON 和读写异常，不应直接崩溃。
- 学生切换时自动加载各自的学期参数、课程模式、课程、当前周次。建议默认跳到该学生的当前周（超出学期可显示可解释的空课表）。

## 1. 课程表主页

- 默认宽高均600 DIP，最小520×480 DIP，在当前屏幕可用区域中央启动。工具区分两行，时间列缩窄，七个星期列等宽。

- 不显示右侧「课程列表」面板；整个可用宽度分配给课程表。
- 顶部左侧显示课程表标题与 `第 N 周`，**不要在第 N 周后附加日期区间**。移除第一行上一周/下一周左右按钮，保留「回到本周」按钮。
- 鼠标在课表区垂直滚轮切换周次：向上上一周，向下下一周；必要时加入滚轮节流，避免一次滑动跳跃多周。回到本周按钮从当前系统日期与学期配置重新计算。
- 每列标题显示「周几」和其下对应的真实 `MM/dd` 日期（年份变更仍正确）。日期以当天实际日期计算，不能从截图抄写。
- 七列顺序：若 `周日归属=上一周`，显示周一、周二、周三、周四、周五、周六、周日；若 `周日归属=下一周`，显示周日、周一、周二、周三、周四、周五、周六。周日列**仅显示「周日」及日期**，不要显示「（下一周）」字样。
- 纵向按个性化设置显示 8 节或 10 节。8 节为上午 4 节+下午 4 节；10 节另加晚上 2 节。每节左侧列出第几节及起止时间。
- 一个课程用固定颜色，名称一致不应仅据名称推断身份（以课程唯一 ID 定义颜色），相同课程在各周和多个时段始终同色。色块仅显示 **课程名称、上课地点**，不显示教师。双节模式一个课程占连续两节，建议视觉上合并成跨两行块；不可以把双节作为两门独立课程。
- 双击任何空白课程格：新建课程，初始时段预填所双击星期与节次；双击有课程的格：打开该**整门课程**的编辑窗口，列出它所有时段。主页无需额外课程侧边栏。
- 一名学生的所有课程统一为**单节模式**或**双节模式**，模式位于个人总体设置中，而**不是课程级设置**；不同学生可不同。双节默认允许 `1~2,3~4,5~6,7~8`（10 节还有 `9~10`）；单节允许 1,2,...8/10。不可跨午休用 `4~5` 等不配对组合。

## 2. 总体设置（每个学生独立）

窗口标题 `总体设置（当前学生姓名）`，设置集中在一页，不设置空白或重复的导航页。

总体设置默认600×600 DIP；新增学生为480×300姓名小窗。所有独立对话框与直接父窗口中心对齐。仅总体设置包含基本信息、课时参数、课时预览，纵向排列，中间可滚动，底部按钮与信息栏固定；文本框和时间下拉框均为圆角。

「基本信息」按以下固定顺序排列，标签列、控件列统一对齐，行距均匀：

1. `第一周周一` —— 不可编辑的日期标签与右侧日历图标按钮，垂直居中。点击展开浅色圆角日历，仅允许选择周一，不提供自由日期输入。
2. `本学期总周数` —— 数字控件，示例值 `20`，允许合理正整数范围。
3. `周日归属` —— 单选按钮 `上一周` / `下一周`。
4. `每日课时` —— 单选按钮 `8 节` / `10 节`，**不显示上午/下午/晚上等附加解释文字**。

「课时参数」纵向排列：

1. `课程时长` 数字文本框，默认45分钟，范围1–180。
2. `奇数节后` 数字文本框，默认10分钟。
3. `偶数节后` 数字文本框，默认20分钟。

两个课间文本框只接受最多两位ASCII数字，范围0–99分钟。总周数和课程时长也只接受ASCII数字；空值不能保存，键入、粘贴、IME、拖放均受限制。

上午/下午/晚上起点分别使用“[小时] 点 [分钟] 分”两组不可编辑下拉框。上午小时仅8/9/10/11；下午仅13/14/15/16；晚上仅18/19；分钟仅00、05、…、55。参数仍保存为HH:mm。已有不在这些选项内的起点明确显示并保留，不自动取整；完整主动选择后才替换。实际课时仍可单独修改。

生成按各段起点进行，不以短课间推算午休或晚餐。修改参数本身不覆盖实际时刻；点击课时预览标题右侧刷新图标时直接执行，不确认、不显示成功提示。参数无效、时间重叠或跨午夜时保留原表并在底部报错。

**课程模式**：`单节` / `双节`（单学生唯一模式），放在「每日课时」之下，默认单节。当前已保存课程数为0时可修改；有课程时只读，不能同次删除课程并改模式来绕过，须先删除全部课程并保存。单节学生不能创建双节安排，双节学生不能创建单节安排。

设置窗口任意位置的滚轮都滚动外层页面，不滚动表格或更改下拉值。时间下拉不显示箭头及其预留空间，最多显示4项，滚动条统一11 DIP；浮层内滚轮转发整页并收起列表。日历浮层是例外：向上上一月、向下下一月，每次仅一个整月；相邻月日期留空，仍只可选周一。

「课时预览」标题不带格式说明，下方无说明文字；右侧刷新图标的tooltip为“根据参数生成默认时间”。五列表头为`节次`、`开始时间`、`结束时间`、`时长（分钟）`、`课后间隔`；各列等宽、数据行与表头等高，文字水平和垂直居中。仅开始/结束可编辑，其余计算只读；第4、8节及当天最后一节的课后间隔显示`—`。保存/取消/恢复默认置于固定底部；恢复默认需窗口内确认，只恢复本学生课时参数与实际时刻。

### 周次与周日规则

- 用第一周周一 `M` 作为学期起始锚点，周序列每 7 天递增。周日归属会改变 **该周包含的周日及排列位置**：
  - 上一周：第 n 周的周一为 `M+7(n-1)` 天，周日为 `M+7(n-1)+6` 天，最后一列。
  - 下一周：第 n 周的周一仍为 `M+7(n-1)` 天，周日为 `M+7(n-1)-1` 天，第一列。
- 自动计算当前第几周时按归属正确处理星期日边界；第一周前的日期、学期结束后的日期需给出清晰状态或允许无课程周视图，而非负数索引或崩溃。
- “第一周周一”与“周日归属”的定义要在界面 tooltip / 帮助说明一致。周次范围为 1~总周数，如何处理范围外预览应明确（推荐显示提示并禁用向外翻页）。
- 切换周日归属必须保持所有课程实际日期不变，自动重算周次；previous→next的周日周次+1，超出总周数自动扩展。反向若产生第0周，自动将第一周周一前移7天并重算全部课程周次、按需扩展总周数，不要求用户手动处理课程。

## 3. 新建/编辑课程（同一个窗口）

- 双击空白格为「新建课程」；双击现有课程为「编辑课程」，只编辑**一门课程**，窗口结构相同。字段：课程名称、颜色、备注（可选）。教师无需出现在主表格，现阶段也无需课程编辑里强制设置教师。删除课程操作仅在编辑模式显示，并二次确认。
- 只有一组「上课时段设置」，**不再设置额外的全课程“上课周次”区域**。
- 课程窗口540×550 DIP；颜色为#RRGGBB圆角文本框及色块预览，新建按已有色相的最大空档随机选柔和颜色，编辑不重新生成。
- 表格精确列顺序：**上课周次 | 时间 | 上课地点 | 操作**。每行都是可独立指定的课时安排：一门课程多个星期、不同节次、不同周次、不同地点可以共存；每行的「操作」至少有删除图标。
- 双击表格真实空白新增时段，双击实际行或编辑图标修改；不显示下方添加按钮。表格随行数增高，使用窗口外层滚动，末尾始终保留可新增的空白区域。表头、滚动条、操作按钮不触发空白新增。
- 保存时校验课程名、至少一条有效时段、周次范围与冲突。未保存关闭需询问。不能因为按学生设置改变单双节而悄悄更改已有课程安排。

## 4. 新增/编辑单条上课时段（独立小窗口）

标题根据场景 `新增上课时段` / `编辑上课时段`，共用320×340 DIP小窗。依次排列：

1. `上课周次`：仅ASCII数字、英文连字符、英文逗号与空格；如 `1-5, 7, 8`。去重排序、连续周次压缩显示，周次受学期范围约束。
2. `周次筛选`：自定义、仅单周、仅双周，按绝对周次筛选。
3. `时间`：仅ASCII数字。一位星期（周日7）+两位节次，双节追加两位结束节；如401、30102。按当前学生模式校验，双节仅1/2、3/4、5/6、7/8及10节制9/10。
4. `上课地点`：允许留空，保存为 `""`。
5. `取消` 与 `确定`。

如果从空白格创建，星期与节次默认预选对应格；若双节，点击同一配对内任一格，默认选中该配对。

## 校验与信息提示

- 同一学生的课程安排发生冲突时禁止保存；同课程内部重复时段也需检查。周次越界、无效节次、空课程名等均禁止保存。
- 所有错误和警告只显示在对应窗口底部信息栏，不弹出警告框。包括模式不匹配、非法JSON、文件读写失败等。
- 单条提示约5秒，最多10秒；有多条消息时按队列每约5秒切换一条，计时从该条实际出现开始。队列清空后文字消失，提示栏折叠。
- 删除、恢复默认及丢弃修改仍需窗口内确认；课时预览刷新是明确例外，直接执行，不以错误警告弹窗实现。

## 管理课程与时间编码

管理课程为“课程名/周次/时间/地点”四列，按课程ID分组，同课各条时段聚拢，每条时段独占一行，课程名为真正纵向合并且居中的单元格。同名不同ID不合并。组内按最早周次、星期、开始节排序，再按完整周次集合、地点、ID稳定排序。选任意单元格突出整组，删除整门课程并在窗口内确认。下方仅“新建”“删除”，Esc或标题栏关闭。

双击组内任意位置编辑整门课程，双击内容区真实空白新建，排除表头和滚动条，不依赖旧选中项。周次用1-5, 7, 8等压缩区间显示；时间不带周次，单节401、双节30102，周日7。

周次解析格式化及时间编码解码使用统一函数；按学生设置验证，JSON保持结构化时段，不重复保存显示字符串。

## UI 质量要求

- Windows 11 类浅色现代风格：12~16px 圆角、柔和边框/阴影、低饱和色块、正确中文字体回退、无多余装饰。
- 高 DPI (100/125/150/200%) 下无裁切；窗口可调整大小，表格随宽度伸缩。对话框尺寸不应超出低分辨率可用工作区，复杂表格可滚动。
- 图标式刷新与设置按钮与学生下拉框紧邻，悬停态、聚焦态、键盘操作和 tooltip 完整；学生下拉框不出现三角箭头。
- 真实日期、时间、节次和周次要从数据计算，**不要照抄参考图中的任何示例日期、错位时刻或色块**。

## 公共样式（2026-10-30修订）

参数标签统一14 DIP深灰蓝，注释标签统一12 DIP灰蓝#718096，字体使用Microsoft YaHei UI/Segoe UI；窗口标题与分组标题保留独立层级。所有下拉选中显示与选项文字14 DIP，选项以浅色#EEF3FA铺满可用区域，6 DIP圆角；选中项底色#E1EBF8。所有窗体、表格、下拉浮层及提示区域的滚动条采用同一样式，竖向宽11 DIP，横向厚11 DIP，圆角灰蓝滑块，保留拖动及轨道滚动。

时段窗口四项参数均左右排列，标签列120 DIP，控件同列对齐、高34 DIP。周次注释“周次：1-5, 7, 8”紧跟上课周次输入，位于周次筛选之前；时间输入后紧跟注释“时间：周几与节次，如 103, 20304。”。默认尺寸不出现滚动条；缩小窗口或消息展开时允许按需滚动。

课程时段表按整行、管理表按整门课程组显示选中效果：共用约22%透明度蓝色叠加层和柔和蓝色边缘光晕，文字深色，单元格边框不使用系统深色焦点高亮。管理表保留课程名单元格原课程色，叠加而不替换；其他单元格按课程组交替白色与#F2F6FB。

## 内容高度与色块修订

课程编辑540×550 DIP，时段320×340 DIP，以完整容纳默认内容、表格与底部按钮并减少空白。多时段和底部消息占用空间时按需滚动；仍保留时段表末尾双击新增空白区。时段标签“上课地点”继续允许空值，周次注释为“周次：1-5, 7, 8”。管理表课程名填色9 DIP圆角，中心保留课程原色，边缘渐变至接近课程组背景色；选中叠加层不替换该渐变。主窗口移除左右切周按钮，滚轮及回到本周保留。
